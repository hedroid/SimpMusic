# Changelog

## 3.0.1 (2026-09-26)

### 修复

- **歌单内搜索白屏（两种失败模式，均为上游 bug，完整技术文档见 `docs/PLAYLIST_SEARCH_WHITE_SCREEN_FIX_2026-09-26.md`）**
  - 过滤态下半屏白屏：搜索过滤到少量结果后内容区之下整片白——页面深色底画在 LazyColumn 且只约束宽度，内容变短时底色跟着缩水漏出浅色窗口底。修为钉满视口高，并推平同病的专辑页/本地歌单页（31da652e、8728d3dc）。
  - 搜索条 blur 白带：haze 2.0 迁移后 blur 层在覆盖层刚出现时渲染成未初始化纯白（滚动后自愈）。垫不透明底色兜底（1f088579）。
- **搜索页切源后不刷新**：长按切源后结果页停留在旧音源内容——原实现只回落 tab 从不重跑搜索。现在切源时若在结果页则按当前 tab 用新音源立即重搜（38c4bf5e）。
- **网易歌"下载到设备"全线修复**（f96c7278）：静默无反应（track 查空回落）、大文件 OOM 崩溃（ktor 流式下载）、同名残占崩溃（预删+EIST 兜底）、百 MB 级慢链路 15s 超时（10min 超时配置）。
- **恢复无版权歌曲置灰显示**：0925 上游合并时丢失的 M9 置灰 UI 按原 diff 恢复（9d06e035）。
- 删除上游带回的 SimpMusic Chart 推广胶囊（fork 已整体移除过的特性被合并复活，c2f6ad05）。
- CR 单二轮复核四项收口：自动备份假成功+旧备份删不掉、cookie 写入锁内时序等（fd2b5a94）。

### 改进

- **灰歌（无版权歌曲）跳过前的转圈从 ~3.7 秒压到 ~0.5 秒**（core ee917bc/0560830/9b131c9）：取流降级链对已知灰歌只试一档（原先逐档走完 3-5 次串行请求）+ 装载失败免重试（原先 0/1/2s 三连重试）+ 队列行判定按 videoId 消除竞态。播放实证的回写让"灰但能播/白但不能播"的队列内漂移自愈收敛。
- **播放页 Info 面板字段补全**（3ad5220+4974d998）：网易歌显示比特率；BPM/调性/调式经 Tidal 富化（凭证不可用时静默）；提取来源记录 NetEase CDN；网易歌隐藏对 YT 概念的 itag 行（ddb69aaa）。

### 其它

- 包体积较 3.0.0 增加约 11MB：系 minSdk 26→31 后 AGP 对 dex 采用未压缩打包（APK 内 STORED），换取安装后更省空间/更快启动/更低内存，属预期行为（对照实验定案，与上游合并无关）。
