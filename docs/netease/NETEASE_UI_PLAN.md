# 网易云音源 UI 接入计划

> 分支 `feat/netease-source`。本文档是 UI 接线阶段的总规划，按推进逐项更新状态。
> 原则：**页面不复制** —— 融合页只动数据层，独立页全部新文件；网易云逻辑一律不进 ViewModel 之上的层（core 封装规矩）。

## 名词约定

- **融合页**：双源数据同页混排，用品牌小角标标识网易内容（YT 为默认源不标）。
- **独立页**：各源各看各的数据。主页/搜索/混合/分类跟随底部导航的音源切换器（长按搜索按钮）；歌单/专辑/歌手/播放页按入口实体自身的 `source` 决定，与全局切换无关。
- **音源切换器**：长按搜索按钮 → 菜单选择，写入 DataStore `selected_source`，持久化（冷启动恢复）。当前页立即刷，其它页下次进入时刷（懒刷新），播放不打断。

## 冲突防控规则（上游合并）

1. 独立页=新文件+挂载点切换，上游屏幕零改动；挂载点是我们拥有的 App.kt/导航层。
2. 融合页的 diff 收敛在两处：ViewModel 数据合并、共享卡片组件加可选参数。
3. 必须动上游 Screen 的场合（歌手页百科、播放页评论按钮）：扩展内容抽独立 composable 文件，Screen 里只留一行插入点。
4. 网易逻辑不进 ViewModel 之上的层；core 已备齐全部端点（40+，真机验证过）。
